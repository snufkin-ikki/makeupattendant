# 登録者募集LP（Webページ版）

`data/cosme-makeup-attendant-lp/` のデザインをもとに、普通のHTML/CSSで作り直したページです。ブラウザで `index.html` を開けばそのまま表示できます。

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体 |
| `styles.css` | デザイン（色・文字・レイアウト） |
| `form.js` | 応募フォームの入力チェック |
| `images/` | 使用している写真・イラスト |

## 公開前に差し替えが必要なところ

`index.html` の中の `[ ]` で囲まれた部分です。

- `[サービスサイトURL]`：ヘッダーの「サービスサイトを見る」のリンク先
- `[面談音声URL]`：「実際の面談を聴く」のリンク先
- `[FORM_ENDPOINT]`：応募フォームの送信先（Formspree などのフォームサービスのURL）。未設定のあいだは送信されません
- `[サービス名]`：フッターの著作権表記
